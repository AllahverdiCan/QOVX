## Privacy Policy / Gizlilik Politikası

**Last Updated:** November 2026

### 1. Zero Data Collection (100% Offline Architecture)
**QOVX** does **not** collect, store, transmit, or share any personal information, telemetry, hardware identifiers, browsing history, or usage analytics. All system optimization, memory management (`EmptyWorkingSet`), cache cleanup, and network latency diagnostics (`ICMP Ping`) are executed **100% locally** on the user's device.

### 2. No Accounts or Third-Party Trackers
- No user registration, login, or account creation is required.
- No third-party advertising SDKs, analytics trackers, or background data collection services are included in the software.
- Network access is used exclusively when the user manually triggers the public DNS latency benchmark or clicks the official developer YouTube channel link.
