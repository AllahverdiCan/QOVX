## English

### 1. Zero Telemetry & 100% Local Processing
- **No Personal Data Collected:** QOVX does not collect, record, transmit, sell, or share any personal information, documents, file names, crash dumps, IP addresses, hardware identifiers, or usage telemetry.
- **100% Offline Architecture:** All system maintenance operations—including working-set memory trimming (`psapi.dll!EmptyWorkingSet`), temporary cache and crash dump cleanup, multi-sample DNS latency testing, DNS cache flushing (`dnsapi.dll!DnsFlushResolverCache`), startup application auditing, and Windows visual performance adjustments—run strictly locally on the user's Windows device.
- **No Third-Party Analytics or Advertising:** The application contains zero advertising frameworks, tracking beacons, or cloud telemetry SDKs.
- **Local Diagnostic Logs:** Internal recoverable diagnostic logs are written exclusively to `%LOCALAPPDATA%\QOVX_Data\qovx_diagnostics.log` with a 512 KB size limit and automatic rotation. All user profile paths are sanitized with `%USERPROFILE%` and `%USERNAME%` tokens. These diagnostic records never leave your device.
- **External Links:** The application only opens external links (such as the developer's official YouTube channel https://www.youtube.com/@ALLAHVERDICAN) when explicitly clicked by the user.
